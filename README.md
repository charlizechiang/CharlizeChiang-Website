# Flat White Coffee website

Static website for Flat White Coffee, 4941 Lincoln Ave, Cypress, CA.

- `site/`: the website. Everything a host needs is in this folder. Open `site/index.html` in a browser to preview it.
- `docs/photos-checklist.md`: photo/video filenames the site expects.
- `content/`: brand notes and the transcribed menu.
- `reference/`: inspiration images and the original menu board (not part of the site).

To publish, upload the **contents of `site/`** to any static host (Netlify, GitHub Pages, Cloudflare Pages, …).
